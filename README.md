# Amigos Seafood & Steak House — página web

Sitio estático (HTML + imágenes WebP) de Amigos Seafood & Steak House, Santiago de los Caballeros, RD.

- `index.html` (inicio), `carta.html`, `eventos.html`, `record-guinness.html`, `en.html` (inglés) y `privacidad.html`.
- `sitemap.xml` y `robots.txt` para Google. Los datos estructurados (Schema.org) van dentro de cada página.
- `fonts/`: tipografías alojadas en el propio sitio.
- `img/`: fotos optimizadas en dos tamaños (`-s` para móvil).

Se publica en Vercel sin paso de compilación.
